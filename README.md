# VetCare - Landing Page Clínica Veterinaria 🐾

Landing page moderna, cálida y completamente responsive diseñada para una clínica veterinaria integral. Construida con HTML5 semántico, CSS3 moderno (Variables CSS, Grid, Flexbox) y JavaScript vanilla sin dependencias externas.

## ✨ Características principales

- **Barra superior de urgencias 24/7** con indicador visual animado.
- **Sección Hero de alto impacto** con llamada a la acción clara, estadísticas de confianza y tarjetas flotantes.
- **Catálogo de servicios** interactivo con iconografía SVG personalizada y tarjeta destacada de urgencias.
- **Sección Sobre Nosotros** enfocada en bienestar animal (*Fear-Free* y *Cat-Friendly*).
- **Testimonios reales** con valoraciones de clientes.
- **Formulario de reserva de citas** con validación en tiempo real, restricción automática de fechas pasadas y confirmación personalizada.
- **Diseño 100% Responsive** con menú móvil desplegable.

## 📁 Estructura de archivos

```text
├── index.html   # Estructura semántica principal
├── styles.css   # Estilos modernos, paleta cálida y media queries
├── script.js    # Menú móvil, validación de formulario y utilidades de fecha
└── README.md    # Documentación del proyecto
```

## 🚀 Cómo visualizar el proyecto localmente

1. Clona o descarga este repositorio en tu equipo.
2. Abre el archivo `index.html` directamente en cualquier navegador web moderno (Chrome, Firefox, Safari, Edge).
3. *(Opcional)* Si utilizas VS Code, puedes usar la extensión **Live Server** para recarga en vivo.
